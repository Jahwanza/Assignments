Problem 1

The p-values from the main effects model suggest that all of the predictors are a statistically significant, and while using the LRT test we observe a p-value = 0 and as such we can reject the hypothesis that the null model and the current model are statistically the same.

The model that was chosen from the backwards stepwise selection is the model that has the lowest AIC = 67.84 which is actually the model with only the main effects.

I compared the models using a chi-squared test to determine if they are statistically different. The P-value for the test = 0.56 > 0.05 and suggests that the interaction model does not provide a statistically significant better fit.

Problem 2

The main effects model provides an AIC=36.138 compared to the AIC of the saturated model = 36.321. The effect of T on the response variable is not statistically significant but the predictor D is statistically significant.

Using our estimates of the main model T=1, using a tracheal tube decreases our log odds of having a sore throat by -1.6. and for every minute increase in duration we have an increase log odds by 0.0687, regardless of device type. Also , the LRT test we observe a p-value << 0.05 and as such we can reject the hypothesis that the null model and the current model are statistically the same.
